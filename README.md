# دستیار صوتی (کنترل گوشی با هوش مصنوعی)

اپ اندروید: شما حرف می‌زنید، Claude صفحه‌ی گوشی را می‌بیند و برایتان کلیک/تایپ/اسکرول می‌کند.

## ساخت فایل نصبی (APK) با گیت‌هاب
1. یک repository جدید بسازید و همه‌ی فایل‌های این پروژه (از جمله پوشه‌ی `.github`) را آپلود کنید.
2. تب **Actions** ← workflow به نام **Build APK** (خودکار اجرا می‌شود؛ یا Run workflow).
3. بعد از ~۵ دقیقه، داخل اجرای تمام‌شده بخش **Artifacts** ← `VoiceAgent-APK` را دانلود کنید و zip را باز کنید.
4. فایل `app-debug.apk` را روی گوشی نصب کنید.

## راه‌اندازی روی گوشی
1. اپ را باز کنید ← «فعال‌سازی سرویس دسترسی‌پذیری» ← «دستیار صوتی» را روشن کنید.
   - اندروید ۱۳+: اگر دکمه خاکستری بود: تنظیمات ← برنامه‌ها ← دستیار صوتی ← ⋮ ← **Allow restricted settings**.
2. کلید API خود را از console.anthropic.com بگیرید، در اپ وارد و ذخیره کنید.
3. دکمه‌ی 🎤 را بزنید و بگویید مثلاً: «یوتیوب را باز کن و دنبال آموزش آشپزی بگرد».

## نکات
- محتوای صفحه برای پردازش به API ارسال می‌شود؛ در برنامه‌های بانکی/حساس استفاده نکنید.
- کلید API فقط داخل حافظه‌ی خصوصی اپ ذخیره می‌شود.
- مدل پیش‌فرض: `claude-sonnet-5-5` (در اپ قابل تغییر است).
